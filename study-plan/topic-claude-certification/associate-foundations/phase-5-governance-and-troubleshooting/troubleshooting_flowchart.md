# My troubleshooting flowchart

| Symptom | First fix to try |
| --- | --- |
| Output is generic or vague | Add a role, context, and an explicit output format |
| Claude misses part of my request | Break the task into ordered steps and ask for one step at a time |
| Output contains wrong or invented facts | Provide the source material, ask Claude to cite it, and verify before using |

Rule: change one thing at a time so you learn what worked.
